# AI Productivity Toolkit for Students — Sales Funnel

## Project Overview

This project demonstrates an AI-powered micro digital business system built around the **AI Productivity Toolkit for Students**.

The system connects three components:

1. AI-powered revenue-focused prompting and sales messaging.
2. Visual AI storytelling for a five-scene advertising campaign.
3. n8n workflow automation for student lead handling and personalized follow-up.

The target audience is students interested in using AI for studying, planning, and workflows.

**Product price range:** ₹499–₹999

## Product Components

The toolkit contains four defined components:

- Prompt Templates
- Study Workflow Systems
- AI-Assisted Planning Structures
- Automation Blueprints

The positioning focuses on an organized student productivity system built around AI, rather than simply offering more AI prompts.

## Project Objectives

- Understand student needs, buying motivations, and objections.
- Develop clear and ethical sales messaging.
- Create a consistent five-scene visual campaign.
- Automate student preview requests and personalized responses using n8n.
- Connect lead information, Google Sheets, email follow-up, and action logging.

## Task 1 — AI Revenue-Focused Prompting System

Designed an iterative prompting system covering:

- Buyer and market analysis
- Product positioning
- Student persona simulation
- Objection handling
- Value and economic ROI framing
- Sales messaging
- Meta-critique and refinement

**Final campaign headline:**

"You Already Have AI. Now Use It With More Structure for Studying, Planning, and Workflows."

The messaging emphasizes organized, reusable structures without promising guaranteed productivity improvements or academic results.

## Task 2 — Visual AI Storytelling

Created a five-scene cinematic advertising narrative featuring Ananya, a 21-year-old Indian college student.

| Scene | Theme |
|---|---|
| Scene 1 | Problem |
| Scene 2 | Hidden Cost of Inefficiency |
| Scene 3 | Introduce Toolkit |
| Scene 4 | Transformation |
| Scene 5 | Purchase CTA |

The visual narrative moves from uncertainty and repeated setup effort toward a more structured approach to using AI.

The same character identity, wardrobe, environment, and visual style were maintained across the scenes.

## Task 3 — n8n Lead Handling Automation

Built an n8n workflow to handle student requests for a free toolkit preview.

### Workflow Architecture

Form Submission → Prepare Student Data → Google Sheets → Switch → Personalized Response → Email → Lead Update → Action Log

### Preview Form Fields

- Name
- Email
- College Year
- Biggest Productivity Challenge

### Challenge Categories

- Time Management
- Lack of Focus
- Overwhelm
- Tool Confusion

The workflow classifies each submission and prepares a category-specific response. It uses the student's submitted email address for follow-up and records the lead and action information in Google Sheets.

### Testing

The project documentation records successful testing of all four challenge categories.
